## How to Deploy via GitHub Pages
1. Push these files to your `portifolio` repository:
   ```bash
   git add .
   git commit -m "Add natural-themed interactive portfolio with updated CGPA and details"
   git push origin main
   ```
2. In your GitHub repository:
   - Go to **Settings** > **Pages**.
   - Under **Build and deployment**, select **Deploy from a branch**.
   - Choose `main` branch and `/ (root)` folder, then click **Save**.
3. Your site will be live instantly!
